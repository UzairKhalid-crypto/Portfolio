# Uzair Khalid — Portfolio Website

Personal portfolio website for **Uzair Khalid**, Lead iOS Developer with 6+ years of experience.

🌐 **Live site:** https://uzairkhalid-crypto.github.io/Portfolio/

---

## About

A single-page portfolio showcasing iOS development expertise, published apps, work experience, and contact information.

## Sections

- **Hero** — Introduction with photo and contact link
- **Services** — iOS App Development, UI/UX Design, App Store Publishing
- **Experience** — Career timeline (TripShepherd, NullBrainer, TechBeyond, CodeCue)
- **Works** — 9 published app showcases with App Store links
- **Contact** — Contact form and direct contact information

## Tech Stack

- Pure HTML, CSS, JavaScript (no frameworks)
- Google Fonts: Nunito + Dancing Script
- Responsive design (mobile-first breakpoints at 768px and 480px)
- CSS Grid & Flexbox layouts
- IntersectionObserver for scroll animations and nav spy
- `rembg` used for hero photo background removal
